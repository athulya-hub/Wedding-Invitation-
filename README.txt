To publish using GitHub Pages:
1. Create a new GitHub repository. A public repository means the files in it can be viewed/downloaded by others.
2. Upload BOTH index.html and welcome-video.mp4 to the repository's main/root folder.
3. Open the repository Settings > Pages.
4. Under Build and deployment, choose Deploy from a branch.
5. Choose the main branch and /(root), then Save.
6. Wait for GitHub Pages to publish and open the site URL shown on the Pages settings screen.

Notes:
- The welcome video is set to autoplay muted and loop. Some phones may still delay playback until the page is interacted with.
- The Canva invitation opens in a new tab.
- Check that the View Location button inside Canva already points to the correct Google Maps location.
- Do not upload private or sensitive videos to a public repository.
